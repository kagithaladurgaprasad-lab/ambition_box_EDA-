# 🚀 Corporate Employee Trends & Compensation Analysis

An end-to-end **Exploratory Data Analysis (EDA)** project focused on understanding corporate hiring trends, salary distribution, employee satisfaction, and compensation patterns using real-world data collected through web scraping.

This project demonstrates how data analysis can transform raw employment data into meaningful business insights that support better hiring and compensation decisions.

---

# 📌 Project Overview

The objective of this project is to analyze employee reviews, salary trends, hiring patterns, and company performance using publicly available corporate data.

Using Python and various data analysis techniques, the project uncovers hidden patterns, identifies market leaders, and provides actionable insights into employee compensation and organizational hiring behavior.

---

# 🔍 What I Did

- Collected real-world corporate data through automated web scraping using **Requests** and **BeautifulSoup**.
- Cleaned and preprocessed the dataset by handling missing values, removing duplicates, and standardizing salary formats.
- Performed **Univariate, Bivariate, and Multivariate Analysis** to explore relationships among different variables.
- Created informative visualizations to identify hiring trends, salary distributions, company performance, and employee satisfaction.
- Extracted business insights to understand factors influencing employee reviews and compensation.

---

# 📊 Key Insights

### 📈 Hiring Trends

- Hiring opportunities are concentrated among a few leading companies.
- **Accenture** emerged as one of the highest hiring organizations.

### 💰 Salary Analysis

- Salary distribution is highly skewed across companies.
- Companies such as **TCS** appear as significant compensation outliers.

### ⭐ Employee Satisfaction

- A strong positive relationship exists between employee salaries and review ratings.
- Organizations offering competitive compensation generally receive better employee feedback.

### 🌍 Location Analysis

- Metropolitan cities such as **Bengaluru** and **Hyderabad** dominate job opportunities.
- Major technology hubs consistently provide higher salary packages.

---

# 💡 Business Insight

Competitive compensation plays a crucial role in improving employee satisfaction and attracting skilled professionals.

Organizations aiming to recruit top talent should align their salary structures with market standards, as higher hiring volume alone does not guarantee a positive employee experience.
